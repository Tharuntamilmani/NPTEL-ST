1. Consider a variable num of type float. Suppose a particular method has a statement if(log(num) >= 0.72), will it be considered a definition of num or a use of num?
Reason: Reading or evaluating the value of a variable in an expression or condition (like inside log(num)) is a use of the variable, not a definition (assignment/modification).
2. Consider a variable count of type int. Suppose there is a statement of the type count++; which of the following statements are correct regarding the data flow definition of count?
Reason: The expression count++ first reads the existing value of count (making it a use) and then increments and stores the new value back into count (making it a definition).
3. State true or false: For every variable in a particular program, every definition of a variable will always reach a use.
Reason: False. Definitions can be "killed" or overwritten before ever reaching any use, or they might occur in dead code blocks that never execute.
4. Which of the following best defines a du-path for a variable x?
Reason: A definition-use (du) path is a simple path (no nodes repeated) starting at a definition of a variable and ending at a use of that variable, which is def-clear with respect to that variable in-between.
5. State yes or no: We group du-paths with respect to a variable by its uses.
Reason: No. In data flow testing, du-paths are generally grouped with respect to variables by their definitions (forming def-use pairs originating from each definition).
6. Which of the following properties should a side-trip taken to cover a du-path satisfy?
Reason: A side-trip must be def-clear with respect to the variable so that the original definition is not accidentally redefined or killed during the side trip.
7. Is it true that prime paths coverage (a structural coverage criterion that we saw earlier) subsumes all-du-paths-coverage?
Reason: True. Prime path coverage is a more rigorous structural coverage criterion that structurally encompasses and subsumes data-flow criteria like all-du-paths coverage.
8. Which of the following statements are true when it comes to comparing traditional source code coverage criteria with graph based coverage criteria?
Reason: In control flow testing, source statements map directly to graph nodes (making node and statement coverage equivalent), and code branches/decisions map to graph edges (making edge and branch coverage equivalent).
9. Which of the following defines a linearly independent path of execution in a control flow graph?
Reason: A linearly independent path introduces at least one new edge or set of processing instructions not included in any other independent paths, meaning it does not contain other paths within it.
10. State true or false: An algorithm for enumerating prime paths works by enumerating all simple paths in order of increasing length and stops when there are no more such paths.
Reason: True. The standard prime path generation algorithm systematically finds all simple paths of length $k$, extends them to length $k+1$ where possible, and stops when no further simple paths can be lengthened or added.
